## <img src=".github/assets/icons/user.svg" width="22" align="absmiddle" alt="" /> 关于我

- 主力方向是 **跨平台客户端**：一套 Flutter 代码打通 Android / Android TV / iOS / Windows / Linux / macOS
- 顺手做 **系统级工具**：输入、滚动、窗口这类最底层的手感，能改就自己改
- 也在做 **AI 本地化**：小说生成、角色记忆、素材整理，让模型落进本地工作流
- 常用 Flutter / Dart、Python、TypeScript，桌面端和系统底层也自己写
- 风格：能跑、好用、有点酷，最好还带点不科学
